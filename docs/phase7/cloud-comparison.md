# Cloud comparison

No provider and no region are selected. This note is a price comparison for a small footprint: one application server, one managed PostgreSQL database, and private file storage. It is not a deployment decision.

Figures below are published on-demand list prices gathered on 13 October 2026. They exclude tax, support plans, egress, and backups.

| Option | What was priced | Published monthly compute | Source |
| --- | --- | --- | --- |
| AWS Middle East (UAE), me-central-1 | Linux t3.small, 2 vCPU, 2 GiB | 18.32 USD | [AWS t3.small regional catalog](https://aws-pricing.com/t3.small.html), checked 12 October 2026 |
| AWS Middle East (Bahrain), me-south-1 | Linux t3.small, 2 vCPU, 2 GiB | 18.32 USD | Same catalog |
| Stay on the current local deployment | The existing machine | No cloud invoice | This repository |

Database, disk, and outbound traffic are additional in both AWS regions. A UAE region keeps data closer to the business. Bahrain is the same compute price in this catalog and is a different country. The local deployment has no cloud bill and no residency commitment from a provider.

Selected provider: none. Selected region: none.
